📚 Automatic Question Pool

যেভাবে কাজ করবে

1️⃣ Quiz Title লিখুন
2️⃣ Class নির্বাচন করুন
3️⃣ Subject নির্বাচন করুন
4️⃣ প্রয়োজন হলে Chapter নির্বাচন করুন

তারপর Question Bank-এর matching Active প্রশ্নগুলো দিয়ে system নিজেই Quiz Pool বানাবে।
