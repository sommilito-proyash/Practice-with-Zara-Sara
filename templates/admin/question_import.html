১. ফাইল প্রস্তুত করুন

ZIP-এর bulk_question_import_template.xlsx অথবা এই পেজের Template ব্যবহার করুন। Questions sheet-এ নিজের data দিন; Examples sheet শুধু format বোঝার জন্য।

  • আবশ্যক: Class, Subject, Chapter, Question, Option A–D, Correct Answer
  • Difficulty: easy / medium / hard
  • Marks খালি রাখলে 1 হবে
  • Quiz Title দিলে একই import-এর প্রশ্নগুলো দিয়ে Quiz তৈরি হবে
  • Correct Answer: A/B/C/D, 1/2/3/4 অথবা option-এর exact text
  • Class: 1 থেকে 12 (যেমন 1, Class 9, Grade 10, শ্রেণি ১২)
  • একবারে সর্বোচ্চ 12000 data row
